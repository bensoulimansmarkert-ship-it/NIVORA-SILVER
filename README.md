# NIVORA SILVER — MOBILE GITHUB + BACKEND PACKAGE

هذه النسخة تحافظ على التصميم الأساسي وتصلح مشكلة تسجيل الدخول التي تظهر على GitHub Pages بسبب محاولة قراءة صفحة HTML على أنها JSON.

## تشغيل مباشر على GitHub Pages (وضع التجربة)
- افتح `admin/login.html`.
- اسم المستخدم: `admin`
- كلمة المرور: `123456`
- الوضع الافتراضي في `js/config.js` هو `MODE: "demo"` حتى تعمل الواجهة الثابتة على GitHub Pages بدون Backend.
- هذا الوضع للتجربة فقط وليس حماية إنتاجية.

## التشغيل الحقيقي
1. شغّل مجلد `server` على استضافة Node.js.
2. استخدم HTTPS.
3. افتح `js/config.js` وعدّل:
   `MODE: "api"`
   و `API_BASE_URL` إلى عنوان الخادم الحقيقي، بدون `/` في النهاية.
4. غيّر كلمة مرور admin وJWT_SECRET قبل الإنتاج.
5. لا تضع مفاتيح AliExpress/DSers داخل GitHub.

## بيانات الدخول التجريبية
