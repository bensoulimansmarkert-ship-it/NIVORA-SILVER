# ربط AliExpress / DSers

## ما هو جاهز؟
- قاعدة بيانات تحفظ sourceProductId و supplierUrl و sourcePrice و shippingCost و profitPercent.
- لوحة الإدارة تستقبل رابط AliExpress وتضعه في import-queue.
- حساب سعر البيع موجود في البيانات.
- الطلبات تحفظ التكلفة والربح المتوقع.

## ما يحتاج اعتمادًا خارجيًا؟
جلب الاسم والصور والمتغيرات والسعر من AliExpress تلقائيًا يحتاج API معتمد أو تكامل DSers. لا تضع App Secret أو API Key في ملفات GitHub العامة.

## الصيغة الافتراضية
Selling Price = (Source Price + Shipping Cost) × (1 + Profit % / 100)

إذا كنت تقصد "هامش 10% من سعر البيع" وليس "زيادة 10% على التكلفة"، يجب تغيير المعادلة إلى:
Selling Price = Cost / (1 - 0.10)

## الشحن
يمكن للمورد إرسال المنتج مباشرة إلى العميل عندما يدعم ذلك المنتج/البائع/طريقة الشحن. يجب اختبار كل مورد إلى مصر قبل نشر المنتج.
